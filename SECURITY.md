# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository or in the deployed portfolio, please report it privately through GitHub's private vulnerability reporting feature.

Please do not disclose security vulnerabilities through public issues, discussions, pull requests, or other public channels.

When submitting a report, include enough information to reproduce and evaluate the issue, such as:

- A description of the vulnerability.
- The affected component or endpoint.
- Steps to reproduce the issue.
- The potential security impact.
- Any relevant logs, screenshots, or proof of concept that do not contain sensitive information.

Reports will be reviewed as soon as reasonably possible. Additional information may be requested during the investigation.

## Scope

This policy applies to the source code contained in this repository and to the production deployment of the portfolio at `arthurfranklin.com.br`.

Third-party services and infrastructure used by the project are subject to their respective security policies.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a reported vulnerability.

Do not perform destructive testing, attempt to access data that does not belong to you, degrade service availability, or use a vulnerability beyond what is necessary to demonstrate its existence.
