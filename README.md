# Arthur Franklin | Portfolio

Portfólio profissional desenvolvido para apresentar minha trajetória, competências técnicas e projetos voltados para Infraestrutura de TI, Suporte Técnico, Monitoramento e Automação.

> 🚧 Este projeto encontra-se em desenvolvimento contínuo e recebe melhorias frequentes.

---

## Sobre o projeto

Este repositório contém o código-fonte do meu portfólio profissional, desenvolvido com foco em desempenho, organização e boa experiência do usuário.

O objetivo é centralizar minha presença profissional e apresentar projetos, tecnologias e experiências relacionadas à área de Tecnologia da Informação.

---

## Tecnologias

- React
- TypeScript
- Vite
- Bun
- TanStack Router
- CSS

---

## Funcionalidades

- Página inicial (Hero)
- Sobre
- Competências técnicas
- Projetos
- Áreas de atuação
- Contato
- Layout responsivo

---

## Executando

```bash
git clone https://github.com/arthurcfranklin/portfolio.git

cd portfolio

bun install

bun run dev
```
